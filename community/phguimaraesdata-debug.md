# 📊 Contribuindo com Git e GitHub

Este repositório foi desenvolvido como parte do **Lab "Contribuindo em um Projeto Open Source no GitHub"** da [Digital Innovation One (DIO)](https://www.dio.me/).  
O foco é praticar o fluxo de contribuição em projetos open source, utilizando ferramentas essenciais do ecossistema Git/GitHub.  

---

## 🚀 Atividades realizadas
- Criação do **fork** do repositório original.  
- **Clone** do fork para o ambiente local.  
- Criação e edição de arquivos.  
- **Commit** e **push** das alterações para meu fork.  
- Configuração do **remote upstream** para sincronizar com o repositório original.  
- Abertura de um **Pull Request**.  

---

## 🧠 Aprendizados pessoais
Durante a prática, pude consolidar conceitos importantes como:
- A diferença entre `origin` (meu fork) e `upstream` (repositório original).  
- Como manter meu fork sempre atualizado com o projeto principal.  
- A importância da organização e da clareza nas contribuições open source.  
- Como pequenos passos de colaboração constroem grandes projetos.
